# GlaserVortex
Scripts for "Robustness of Off-Axis Electron Vortices in Nonuniform Magnetic Fields ([arXiv:2607.22315](https://doi.org/10.48550/arXiv.2607.22315))"

## Instruction
The code depends on these Python packages:
- numpy
- scipy
- mkl_fft
- matplotlib

## Usage
1. run 'Schrodinger_Glaser_v3.py'
2. move 'QM3d-plt.ipynb' into the folder './output-schrodinger-Glaser/'
3. run 'QM3d-plt,ipynb'
