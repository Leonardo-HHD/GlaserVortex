# GlaserVortex
Scripts for "Robustness of Off-Axis Electron Vortices in Nonuniform Magnetic Fields ([arXiv:2607.22315](https://doi.org/10.48550/arXiv.2607.22315))"

## Dependencies
- numpy
- scipy
- mkl_fft
- tqdm
- matplotlib

## Usage
1. run 'Schrodinger_Glaser_v3.py'
2. move 'post_proc.ipynb' into the folder './output-schrodinger-Glaser/'
3. run 'post_proc.ipynb'
